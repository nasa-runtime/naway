# Support

Naway is a community-maintained open-source project and does not provide a
guaranteed support service or response-time SLA.

## Getting Help

- Read `README.md`, `naway.md`, the protobuf contract, and the relevant SDK documentation.
- Search existing GitHub Issues before opening a new report.
- Use a bug report for reproducible defects.
- Use a feature request for scoped product proposals and compatibility needs.

When requesting help, include the Naway version or commit, operating system,
enabled Cargo features, relevant sanitized configuration, expected behavior,
actual behavior, and a minimal reproduction when possible.

Never post credentials, tokens, internal addresses, customer data, or production
payloads. Report suspected vulnerabilities privately as described in `SECURITY.md`.
