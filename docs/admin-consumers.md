# 集群消费者绑定

管理端口的 `/consumers` 汇聚集群各节点已发布配置中的原生 API-Key 消费者绑定。平台管理员可以
查看整个声明集群；工作区成员只能读取平台声明的本工作区节点及归属一致的绑定。纯 Admin
通过管理 gRPC 接收 Data 和 all-in-one 节点事实，各管理入口共享相同的身份和分页规则。

## 目录包含什么

每条绑定描述显式 `consumer`、HTTP 入口、路由、编译后凭据序号、来源 `header` 或 `query`
及其名称、`enabled`、本路由实际选择的用量套餐、工作区、租户与环境。套餐选择包含已编译的
显式消费者绑定、消费者组和路由缺省套餐；路由未配置用量套餐时不推断套餐已执行。

同一消费者在不同入口、路由或凭据序号下分别列出。相同绑定的来源、状态、套餐或归属不同，
页面按节点展示变体。凭据序号仅标识当前编译配置中的位置，不能作为原始 `filters` 下标用于
编辑。目录不包含密钥原值、验证摘要、内部凭据指纹、SecretSource 或秘密文件路径。

目录不枚举没有显式 `consumer` 的 API-Key、外部身份提供方的全部用户，也不把运行时认证
结果推断为可枚举身份。已声明但禁用的凭据仍显示，禁用不代表删除；实际认证与撤销语义见
[原生 API-Key](api-key.md)。显示已启用只说明活动策略中的声明，不保证请求同时满足其它
认证方式、权限、限流或配额条件。

## 节点覆盖与读取权限

平台接口为 `GET /api/cluster/consumers`，同时需要 `cluster/read` 和 `consumers/read`。
工作区接口为 `GET /api/workspaces/{workspace}/cluster/consumers`，需要当前工作区读取权，
不授予平台消费者权限。工作区只使用平台声明的 `cluster_nodes`；没有声明成员时返回
`unconfigured`，不会退回本机或扩大到整个集群。

工作区读取还要求节点对象目录提供同一配置代的读取权限证明，并与管理入口的工作区权限一致。
绑定必须同时匹配工作区、租户和环境，过滤发生在搜索和分页之前。权限证明缺失、旧协议、
节点失联、身份冲突和容量不足都不能证明某个绑定不存在。

| 状态 | 含义 |
| --- | --- |
| `available` | 当前节点的完整消费者目录可用于读取 |
| `pending` | 当前配置的分片或工作区证明尚未完整收到 |
| `unsupported` | 节点未声明消费者目录能力，或不提供所需工作区证明 |
| `stale` / `unknown` | 节点报告过期，或尚无当前节点事实 |
| `authority_mismatch` | 工作区读取权限证明与当前管理入口不一致 |
| `identity_conflict` | 节点身份存在冲突，不能选取其中一份事实 |
| `capacity` | 节点或接收目录超出观察容量，不能交付半份清单 |

每条绑定分别返回 `missing` 和 `unknown` 节点。只有完整且已授权的目录未包含该绑定，才能
计入 `missing`；其它情况保留在 `unknown` 和完整成员分母中。平台响应还提供集群成员目录的
覆盖边界，不能把仅本机可见或成员发现不完整解释成全集群完整。

## 查询与页面有效期

接口接受 `search`、`offset` 和 `limit`。搜索区分大小写，匹配消费者、入口或路由，最多64字节；
每页1至100项，缺省25项，偏移不超过4096。重复参数、未知参数和非法范围返回400。
跨节点最多汇聚4096个匹配绑定；超限返回503，需要缩小搜索范围。

响应 `ETag` 根据授权范围和当前节点配置向量生成。后续页必须携带前页 `ETag` 作为 `If-Match`，
缺少返回428；节点配置、目录或覆盖变化返回412，应重新读取第一页。不同 Admin 入口在节点
事实一致时产生相同分页身份。响应上限4 MiB，读取与对象目录共用八个并发许可；忙时返回429。
平台当前采样不可用时返回202，不以本机消费者接口替代集群结果。

页面每两秒读取当前页，结合 `x-naway-sample-age-ms` 和网络耗时限制显示有效期。搜索条件、
范围、页码变化会退休旧请求；暂停、隐藏、退出、失败或过期时清除旧事实。页面不提供历史
查询。401、403或404后停止自动读取，恢复需要显式操作并重新通过服务端授权。

## 数据提交与配置修改

节点从不可变执行快照收集一次目录，通过 `Arc` 在本机和所有接收目标间共享；不因浏览器读取
或心跳重复解析 YAML、读取秘密文件，也不增加普通代理请求路径的锁或序列化。

独立管理 `Consumers` RPC 复用既有 mTLS、节点证书绑定、启动身份、接收端会话和配置发布门。
发送端及接收端通过心跳声明能力；旧端未声明时保持 `unsupported`，其它管理目录与心跳继续
工作。消费者分片与对象目录串行占用同一发送槽，另一个槽用于指标，不增加常驻在途 RPC。

每节点最多2048条绑定、512 KiB保留容量，接收槽共享64 MiB；每片最多16条，每轮最多八片，
与心跳及其它目录共用原有绝对期限。消费者与来源名称最多256字节，其它身份字段最多128字节。
接收端先核算总槽预算，再按实际字符串容量计费。只有偏移连续、身份排序唯一、重复内容一致、
完整摘要匹配的目录才能发布。分片不会刷新心跳；新配置、会话退休或能力撤销会使旧目录失效。
超出观察容量不改变正在执行的业务认证策略。

此页面提供读取。配置修改使用[结构化候选编辑](admin-draft-editing.md)中的路由密钥、消费者
套餐绑定和用量策略，再通过[持久管理提案](admin-operations.md)、
[原目标预览](admin-target-preview.md)与审批执行。只读目录不绕过审批，不提供跨节点原子撤销
承诺，也不直接调用本机消费者删除接口。
