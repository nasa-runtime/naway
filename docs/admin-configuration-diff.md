# 配置候选差异

`POST /api/config/{kind}/diff` 使用 `Content-Type: application/yaml`，要求平台配置的
`dry-run` 权限。`kind` 可选 `all`、`routes`、`sentinel`、`upstreams`、`listeners`；
`sentinel` 接收规则文档，其余类型接收完整主配置文档。候选通过与发布相同的完整构建器，
差异请求不改写活动文件，也不发布配置。

每次比较冻结当前管理节点的一个活动快照，从该版本归档取回其它文档。可将配置读取响应的整体
ETag 放入 `If-Match`，只接受唯一且精确匹配的值；不匹配返回 `412`。不带 `If-Match`
也不会混用版本：读取正文或构建期间发生配置切换时返回 `409`。构建结束后重新认证并检查权限，
已失效凭据返回 `401`，无权限或主体发生变化返回 `403`。成功响应带整体 ETag 和 `no-store`。

响应中的 `scope: local` 表示本次比较来自该管理节点的活动基线，不能据此推断其它节点已经校验
或发布。集群变更仍须使用[持久管理提案与执行](admin-operations.md)，由冻结的各原目标执行预检、
应用、必要补偿和效果确认；独立 Admin 与 Data 的文件可以不同。

Sentinel 差异按 `flow/id` 和 `degrade/id` 返回 `added`、`removed`、`changed`，只包含业务标识。
比较使用活动与候选快照各自实际加载的 NAML profile、环境覆盖结果，覆盖全部类型化字段和同一路由
内的执行顺序。预热缺省 `cold_factor=3`、`cold_after_ms=warmup_ms` 与显式相同值等价。
每种规则类型内的 id 必须唯一，禁用规则也占有该身份；禁用状态或规则字段变化可以被识别。
规则正文、环境求值内容及内部构建错误链不会出现在差异响应中。

上游差异按声明服务名返回 `added`、`removed`、`changed`。同名服务会比较已编译的实例地址、
权重与配置状态、协议、TLS 连接池身份、负载均衡、哈希、会话保持、反馈、重试、自适应并发、
健康策略、预热、拓扑、注册服务绑定与陈旧期。预热扫描周期变化会标记启用预热的服务。
比较直接借用不可变策略，不复制实例或凭据；动态发现刷新、实际健康变化、实例加入时刻和反馈
代际属于运行事实，不作为配置差异。上游响应仍只包含服务名，不返回地址、metadata 或凭据。

业务监听差异覆盖 HTTP proxy 和 TCP/UDP stream，名称分别是 `proxy:id` 和
`stream:id:协议`。HTTP 比较完整接入策略、TLS/HTTP3、可信代理、PROXY protocol、资源上限、
超时、HTTPS 跳转与 HSTS；HTTP 路由内容归属路由域。stream 同时比较 preread、UDP 预算、
上下游 PROXY protocol、MQTT/Kafka 治理及路由策略。比较直接借用已编译计划，响应只输出名称。
TLS 比较包含证书来源、SNI、mTLS、OCSP、session ticket、ACME、SPIRE、外部签名和内存材料的
声明策略，不输出证书或密钥；OCSP 缓存和 SPIRE 当前轮换状态不作为配置变化，同路径文件的
原地证书轮换由 watcher 处理。此监听域不包括管理认证和其它控制通道。

HTTP 路由使用独立的代理、路由身份比较，输出 `proxy/route`，每段中的 `%` 和 `/` 分别编码为
`%25` 和 `%2F`。比较包含有效选择次序、原有路由摘要，以及请求/响应头、Cookie、重定向、
正文替换、压缩、CORS、IP/Referer/方法限制、限流/并发/带宽/熔断、固定响应、错误映射、镜像和
超时的实际参数。共享变量计划改变时保守标记全部路由，响应不公开变量、头值或正文。
认证比较覆盖 Basic、API-Key、HMAC、Digest、JWT/JWE、JWKS、OIDC RP、外部鉴权与 `satisfy`
组合的已编译声明。比较包含实际解析的凭据，静态公钥、JWE 私钥及自定义 CA 使用构建时保存的
材料身份识别同路径轮换；材料摘要只用于配置审查，不代替密码验证，也不在响应中输出。
JWKS key/负缓存、刷新锁、OIDC 登录暂存和会话属于运行状态，不参与配置比较。
启用对应 feature 时，SAML 比较实际签名 metadata、固定证书、SP/IdP 身份、ACS、属性映射、
时钟容差、防重放期限和输入预算；LDAP 比较实际服务凭据、目录与搜索边界、StartTLS/CA、映射、
超时和连接上限。材料身份在构建的原读取点冻结，SAML 已消费断言和 LDAP 连接池不参与比较。
本地安全比较包含 WAF 内置规则、已验签规则包及其构建预算，DLP 检查目标和遮蔽策略、CSRF
来源与实际签名凭据、Bot 匹配/行为/签名/速率/挑战策略、Casbin 实际模型与策略材料、请求解压
边界和条件返回表达式。Bot glob 按无序、ASCII 大小写无关的集合比较，材料身份不在请求期计算。
OPA 比较外部服务与内嵌引擎的完整声明、实际授权凭据、输入与 obligation 权限、缓存容量与期限、
分布式和 singleflight 参数、退避边界及实际签名 bundle。缓存内容、flight、工作区租约和当前退避
计数不参与比较。GeoIP 比较实际 MMDB 材料、国家/ASN/匿名网络规则、失败动作、最大数据库年龄
与构建时过期决定；相同材料在候选构建时跨过期限而改变有效动作，也会报告路由变化。
内容比较覆盖请求校验、响应契约的实际展开 Schema、操作选择、媒体与状态规则、正文预算及失败
处置，JSON/XML/SOAP 转换的完整动作和输出 QName，以及 GraphQL guard 与 REST→GraphQL 映射。
Schema 在编译时按类型、长度和有序结构冻结材料身份，对象键顺序不影响比较；不为比较保留原文
副本或重新序列化文档。HTTPS Schema 注册源还比较规范 URL、实际固定摘要、验签公钥、CA 材料、
下载和缓存预算。缓存命中仍复验当前字节上限、签名和 CA；改变 CA 后不能沿用旧信任身份的缓存。
公共 HTTP 缓存比较容量、有效期、状态码、Vary、L2、singleflight、陈旧响应和抖动参数；条目内容、
代际观测、正在合并的请求和工作区租约不参与配置比较。
流量治理比较本地/Redis 后端、双向带宽、多窗口算法、排队、成本来源、可信用量、共享作用域、
失败动作、持久事件开关及 Redis 响应结算预算。冻结的账本身份决定实际额度隔离，身份变化也会
报告差异；余额、队列占用和活动请求不参与比较。套餐比较实际展开后的 consumer/default 绑定和
套餐全部参数，同名套餐改额度也能被识别。mock 与故障注入比较状态、头、正文、概率和延迟。
静态资源比较固定根与安全规范根、文件选择模板、索引、缓存头、MIME、点文件、ETag、Range 及
媒体解析预算；文件正文和 mtime 变化不属于配置差异。CGI 比较完整脚本、记录协议、终止方式、
请求头、连接复用与资源边界，排除空闲连接和正在使用的许可。WebDAV 比较完整声明与冻结的本地
或代理资源身份，排除当前文件锁、目录内容和会话占用；媒体比较也不等待正在执行的解析任务。
CONNECT 比较目标端口、主机与 CIDR、私网及自身地址门、连接和隧道预算。WebTransport 比较
固定上游、规范 Origin、完整会话预算及实际加载的文件或系统信任锚；0-RTT 比较重放保留窗口。
WebSocket 比较完整帧、分片、压缩和时限，以及两个方向有序的 ACL、Schema、脱敏、速率和外部
插件计划。外部插件比较实际凭据、CA 与修改权限；Schema 保留消息专用的非回溯正则限制。
活动隧道、已消费 nonce、消息计数和外呼连接池不属于配置差异，比较不会读取这些运行状态。
其它复杂安全与扩展仍有仅比较摘要的部分，路由差异不能证明全部策略字段等价。

同一管理实例最多同时执行两个候选工作单元。归档读取、构建、比较和私有工作区清理共用该预算；
HTTP 等待者取消不会提前释放仍在运行的工作单元。容量不足返回 `503`，归档不可用返回 `409`，
候选非法返回低敏 `400`。清理无法确认时关闭该实例的新候选受理，已发布的数据路由继续服务。
