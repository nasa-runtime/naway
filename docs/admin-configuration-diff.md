# 配置候选差异

`POST /api/config/{kind}/diff` 使用 `Content-Type: application/yaml`，要求平台配置的
`dry-run` 权限。`kind` 可选 `all`、`routes`、`sentinel`、`upstreams`、`listeners`；
`sentinel` 接收规则文档，其余类型接收完整主配置文档。候选通过与发布相同的完整构建器，
差异请求不改写活动文件，也不发布配置。

每次比较冻结当前管理节点的一个活动快照，从该版本归档取回其它文档。可将配置读取响应的整体
ETag 放入 `If-Match`，只接受唯一且精确匹配的值；不匹配返回 `412`。不带 `If-Match`
也不会混用版本：读取正文或构建期间发生配置切换时返回 `409`。构建结束后重新认证并检查权限，
已失效凭据返回 `401`，无权限或主体发生变化返回 `403`。成功响应带整体 ETag 和 `no-store`。

响应中的 `scope: local` 表示本次比较来自该管理节点的活动基线，不能据此推断其它节点已经校验
或发布。集群变更仍须使用[持久管理提案与执行](admin-operations.md)，由冻结的各原目标执行预检、
应用、必要补偿和效果确认；独立 Admin 与 Data 的文件可以不同。

Sentinel 差异按 `flow/id` 和 `degrade/id` 返回 `added`、`removed`、`changed`，只包含业务标识。
比较使用活动与候选快照各自实际加载的 NAML profile、环境覆盖结果，覆盖全部类型化字段和同一路由
内的执行顺序。预热缺省 `cold_factor=3`、`cold_after_ms=warmup_ms` 与显式相同值等价。
每种规则类型内的 id 必须唯一，禁用规则也占有该身份；禁用状态或规则字段变化可以被识别。
规则正文、环境求值内容及内部构建错误链不会出现在差异响应中。

路由、上游和监听的响应是已构建对象的摘要；其中上游当前只列出服务名增删，路由和监听只比较
所公开的摘要字段。它们不能证明全部策略字段等价。Sentinel 的完整字段比较不扩大这些摘要的能力。

同一管理实例最多同时执行两个候选工作单元。归档读取、构建、比较和私有工作区清理共用该预算；
HTTP 等待者取消不会提前释放仍在运行的工作单元。容量不足返回 `503`，归档不可用返回 `409`，
候选非法返回低敏 `400`。清理无法确认时关闭该实例的新候选受理，已发布的数据路由继续服务。
